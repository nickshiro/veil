# Veil
N.B. A fork of [Xray-core](https://github.com/XTLS/Xray-core). Support its development and respect its licenses.

## Goals
- [ ] Remove dead or poor-quality code, outdated implementations, unnecessary wrappers, excessive configuration, and historical compromises.
- [ ] Reduce and streamline dependencies without sacrificing functionality.
- [ ] Move common networking tasks from application code into standard APIs and components.
